# Data

The dataset is not stored in this repo (about 116 MB).

1. Go to Kaggle and search "Fake and Real News Dataset" (ISOT, by Clement Bisaillon).
2. Download and unzip.
3. Put `Fake.csv` and `True.csv` in this `data/` folder.

Columns: title, text, subject, date.
Fake.csv = 23,481 articles. True.csv = 21,417 articles.
